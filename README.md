# AI Input Writer（AI 剧情扩写）

酒馆（SillyTavern）扩展。把一句剧情梗概，扩写成一段**能直接用的 Input**。

```
你写：「第二天我去了超市买东西」
            ↓
   当前剧情上下文 + 你选的文风 + 可选楼层仿写样本
            ↓
输出：「第二天我起得很早，窗外的光还没完全亮透。我翻了翻冰箱……」
            ↓
      改几个字 → 注入输入框 → 你自己按发送
```

不是让 AI 替你回话，是帮你把「想法」写成「文笔」。

## 它解决什么问题

在酒馆里想推一段剧情，常常遇到两个麻烦：

1. **懒得写**。脑子里只有「第二天我去超市」，但直接发这么一句，角色不好接。
2. **写出来不像**。好不容易写了几行，跟前面角色的语感、叙述密度差一截，读着出戏。

这个扩展把这两步合成一步：你说一句梗概，它读你最近的聊天记录接着往下写，再按你指定的文风（或者干脆学某个楼层的写法）落成文字。写完还能改，改完不替你发送。

## 功能一览

| 功能 | 说明 |
|---|---|
| 剧情延续 | 自动读最近聊天，接得上时间、地点、人物状态，不另起炉灶 |
| 三种文风来源 | 内置风格 / 预设条目 / 世界书条目，可叠加 |
| 楼层仿写样本 | 指定一条已有楼层当语感范本，只学写法不抄内容 |
| 内容清洗 | 自动剔除 `<thinking>` 等思维链标签，只喂正文，防止「连思维链一起仿写」 |
| 字数控制 | 设最小/最大字数，实时显示当前状态 |
| 双 API 模式 | 沿用酒馆当前 API（零配置）或自填 OpenAI 兼容中转站 |
| 可编辑 | 生成结果直接在面板里改 |
| 可最小化 | 生成时收成小圆钮让出聊天区，输入内容不丢 |
| 移动端适配 | 手机上自动全屏布局，处理软键盘遮挡 |
| 绝不自动发送 | 只写进输入框，发不发由你决定 |

## 安装

### 前提

- SillyTavern（酒馆）。开发与实测版本 **1.16.0**，低版本可能缺少用到的接口。
- 建议用 release 分支版本的酒馆。

### 方式一：从 URL 安装（推荐）

1. 打开酒馆，进入**扩展栏**（顶栏右侧的扩展图标）
2. 点 **Install extension**
3. 粘贴本仓库地址：

   ```
   https://github.com/tangbei0820/AI-Input-Writer
   ```

4. 点安装。装完**刷新页面**（`Ctrl + F5` 更保险），不需要重启服务

酒馆的安装机制是 `git clone` 这个仓库到你的扩展目录，所以仓库名会直接成为文件夹名。

### 方式二：手动安装

把本仓库的文件全部放进：

```
<酒馆根目录>/data/default-user/extensions/AI-Input-Writer/
```

`default-user` 是酒馆默认的用户目录，如果你改过用户名就换成自己的。
没有 `extensions` 文件夹就自己建一个。放好后刷新酒馆页面。

> 装完在扩展列表里能看到「AI Input Writer（AI 剧情扩写）」就说明成功了。
> 如果报错说目录已存在，说明之前装过 —— 先删掉那个文件夹再装。

## 快速上手

1. 点底部输入框左侧的**魔杖图标**
2. 菜单里选 **AI 剧情扩写**
3. 在「我想写的是……」里写一句剧情想法
4. 按需选文风来源（见下一节）
5. 点 **生成 Input**
6. 结果出现在下方，直接改
7. 点 **确认并注入 Input** —— 内容进输入框
8. **自己按发送**

生成过程中可以点右上角的 **最小化**，面板缩成右下角一个小圆钮，
方便你一边看聊天记录一边等。再点圆钮展开，**已输入的内容不会丢**。

手机上面板自动变成全屏布局，按钮加大、输入框字号锁 16px（防止 iOS 聚焦时页面被放大），
软键盘弹起时面板高度会跟着缩，输入框不会被键盘盖住。

### 界面

面板走**极简**路线：大量留白，分组只用「淡底色卡片 + 小字距标题」，
没有边框线、没有分割条，配色收敛成 6 个值。

从上到下 4 张卡片就是主线流程：**意图 → 文风 → 仿写样本 → 结果**，
其余配置都收在最底下的「设置」里（默认折叠）。

想改外观：全在 `style.css` 顶部那段 CSS 变量里，改一处全局跟着变。
明暗主题都能自适应。

## 文风来源

面板中间有三个标签页，可以叠加使用 —— 勾了就会一起生效。

### 内置风格

自带的 5 条：白描、细腻心理、文学化、简洁自然、动作强化。
可以勾选多条让 AI 融合使用；也可以「+ 新建风格」自己加，或者删掉不要的。
这一栏的内容可以在面板里直接编辑。

### 预设条目（内联抓取）

**直接读酒馆的 Chat Completion 预设**，把里面的提示词块列出来给你勾。

- 顶上下拉框列出你**所有**的预设，默认选你**当前正在用的**那个，名字后面带「（当前使用中）」
- 读的是预设**文件内容**，**不会切换你正在用的预设**，也不会修改它 —— 只是读
- 默认勾着「只看文风类」，用关键词（writing_style / 文风 / 笔法 / 叙述 / 语感…）筛出相关块
  （想找别的就取消勾选，或者用搜索框）
- 条目旁边标了字数；**点条目下面的预览文字可以展开看全文**
- 勾选会按预设分别记住，切来切去不会丢

> ⚠️ 勾了**就是生效** —— 即使你之后切到别的预设，之前勾的条目还会一起拼进去。
> 统计行会提示「另有 N 个预设的勾选也会一起生效」，不想要就点「清空本预设的勾选」。

### 世界书条目（内联抓取）

- 顶上下拉框列出你所有的世界书，默认选**当前聊天绑定的那本**
- 默认只显示**启用中**的条目（被禁用的显示成半透明，取消勾选「只看启用中」就能看到）
- 搜索框同时搜条目备注、触发关键词和正文
- 条目旁边显示字数和状态（常驻 / 已禁用 / 触发键）
- 勾选按世界书分别记住，跨书叠加生效，规则和预设一样

> 一个预设动辄上千条提示词块、世界书动辄上千条，所以列表最多各显示前 400 / 300 条。
> 找不到就用搜索框缩小范围。

### 仿写样本

选一条**已有的聊天楼层**当语感范本，让 AI 学它的写法。

- 下拉框列出当前聊天的所有楼层，显示成 `#楼层号 角色名：前几个字`
- 楼层号用的是酒馆内部的 mesid（**从 0 开始**）
- 隐藏楼层会标上「[隐藏]」，默认选中最后一条非隐藏的 AI 回复
- 勾「启用」后才生效

拼进 prompt 时会明确要求：**只学句式节奏、用词、描写密度和标点风格，
不许复用范本里的情节、人物名或原句**。

预览那行显示「清洗掉 71 字，剩 19 字」这样的字样，
让你一眼看出思维链之类的部分有没有被剔干净（见下面的「内容清洗」）。

换聊天时楼层列表会自动刷新。

## 内容清洗

**为什么需要它**：很多预设会让模型先把思维链写在 `<thinking>` 之类的地方，正文再放进 `<content>`。
如果整条消息原样喂给 AI 当上下文或仿写样本，它会把思维链的口气也一起学过去 ——
写出来的东西就带上了「她应该先观察我的表情」「这里要写冷一点」这种幕后笔记。

**默认行为**（读上下文 + 读仿写样本时都生效）：

| 规则 | 默认值 | 作用 |
|---|---|---|
| 只保留 | `content` | 只取 `<content>…</content>` 里面的内容 |
| 剔除 | `thinking, think, reasoning, analysis, cot, thought, scratchpad, details, 思维链, 思考过程` | 整块删掉（连标签一起） |

执行顺序：先整块剔掉「剔除」标签 → 再按「只保留」标签提取内容 → 清掉残留标签 → 收敛空行。

几个容错设计：

- 楼层里**没找到**「只保留」标签时，整段原样用（普通聊天不受影响）
- 标签**没闭合**（输出被截断）时，丢掉没闭合的那部分，不会把残渣拼进去
- 用户楼层一般没有这些标签，等于不做处理
- 清洗后为空就回退原文，楼层不会凭空消失

配置在**设置 → 内容清洗**里，可以改成你自己的标签。比如你的预设用
`<正文>` / `<内心戏>`，就在这里写对应名字。多个用逗号分隔，
写成 `<content>` 这种带尖括号的也认。

不想清洗就在那里取消勾选，一切照旧。

## 设置

点面板底部的「设置」展开。

### 生成用的 API

**沿用酒馆当前主 API**（默认）
零配置，用你在酒馆里已经配好的模型，没有跨域问题，也不写进聊天记录。

**自填 API（OpenAI 兼容）**
自己填 Endpoint / API Key / Model。适合想用另一个模型（比如便宜快速的小模型）写草稿。

> 浏览器直连第三方 API 可能被跨域策略拦住。如果报错提示跨域，
> 去酒馆根目录的 `config.yaml` 加上：
> ```yaml
> enableCorsProxy: true
> ```
> 重启酒馆后，勾选设置里的「走酒馆代理」，请求就会由酒馆的服务端转发，不再受跨域限制。

### System Prompt

定义了 AI 的写作身份和规则，可以随便改。点「恢复默认」能还原。

当前默认版强调五件事：延续前文、不擅自加戏、沿用叙述人称、遵循文风、控制字数。
其中「**不擅自添加用户没有要求的重大情节**」是最关键的一条 ——
模型天然爱加戏，不写死这条，它就会替你把剧情推到下一章。

## 铁律：注入 ≠ 发送

**这个扩展在任何情况下都不会替你发送消息。**

代码里不存在点击发送按钮、模拟回车键、或调用发送函数的逻辑。
文字进了输入框之后，发不发、什么时候发，完全由你决定。

### 不会做的事

- 不自动发送消息
- 不修改角色卡
- 不修改世界书（只读）
- 不修改你的预设（只读）
- 不切换你正在用的预设
- 不碰酒馆原有布局

### 数据去哪了

- 配置存在酒馆自己的扩展设置里（随账号走），**不会上传到任何第三方**
- API Key 只存在本地配置，不进聊天记录、不打日志
- 只有你主动点「生成」时，才会有一次请求发往你指定的模型

## 已知限制

- 字数通过 Prompt 约束模型，不是硬截断，偶尔会略微超出或不足。
- 上下文默认取最近 20 条，单条超 800 字截断，总长上限 12000 字。
- 文风素材（预设 / 世界书条目）拼进 prompt 的总字数上限 12000 字，超出会砍尾并在 prompt 里注明。
- 生成期间如果切换了聊天，会提示你结果可能对不上当前剧情。
- 预设条目和世界书条目里的酒馆宏（`{{getvar::x}}` 之类）会在拼进 prompt 时展开。
- 内容清洗只在**读上下文和仿写样本**时生效。预设条目 / 世界书条目是你主动勾选的素材，
  一律原样使用，不做清洗。
- 清洗是按标签名匹配的，跟具体预设无关。如果你的预设把思维链写在别的标签里，
  去「设置 → 内容清洗」把名字加进「剔除」那一栏。

## 常见问题

**魔杖菜单里找不到「AI 剧情扩写」？**
刷新页面（`Ctrl + F5`）。还是不行的话检查扩展列表里这个扩展是不是被禁用了。
另外 `data/` 下的扩展是酒馆启动时扫描的，如果刚手动放进去，重启一次酒馆。

**安装时报目录已存在？**
同名文件夹已经在了。先把旧文件夹删掉（酒馆扩展列表里有删除按钮），再装。

**生成时报跨域错误？**
见上面「设置 → 生成用的 API」。要么切回「沿用酒馆当前主 API」，要么开酒馆的 CORS 代理。

**仿写预览显示「清洗掉 0 字」？**
说明你的预设用的思维链标签名跟默认值对不上。去「设置 → 内容清洗」把实际标签名加进「剔除」。

**结果老是加戏，自己往下推进剧情？**
去「设置 → System Prompt」把「不擅自添加用户没有要求的重大情节」那条再强调一遍，
或者直接在面板里把多加的情节删掉 —— 生成结果本来就是给你改的。

## 兼容性

- **酒馆版本**：开发与实测 1.16.0
- **不依赖任何其他扩展**：不用装酒馆助手（JS-Slash-Runner）也能跑
- **纯原生 JS + jQuery**（酒馆自带），没有构建步骤，没有 npm 依赖
- 理论上与其它扩展共存；面板层级设得较高。如果被别的扩展盖住，欢迎反馈

## 开发与调试

控制台里有几个只读接口，出问题时可以自己看一眼：

```js
AIIW.probe()            // 读到了几个预设 / 几本世界书 / 几层楼
AIIW.cleanPreview(4)    // 第 4 层清洗前后各是什么（含字数）
AIIW.clean('文本')      // 直接测一段文本的清洗结果
AIIW.previewPrompt('第二天我去了超市')   // 看最终会拼出什么 prompt（不含 API Key）
```

改完代码刷新页面即可，不需要重启。浏览器可能缓存 js，用 `Ctrl + F5` 强制刷新。
